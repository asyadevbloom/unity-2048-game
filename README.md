# Unity 2048 Game

A classic 2048 puzzle game built in Unity 6.

## About This Project
This is a learning project created by following the Zigurous 2048 tutorial. 
My personal contribution: exit button and UI adjustments.

## Built With
- Unity 6
- C#

## Status
✅ Completed tutorial version. 
🚧 Planning a future version with another illustrations instead of numbers.

## How to Run
1. Clone this repository.
2. Open the project in Unity 6.
3. Press Play.
